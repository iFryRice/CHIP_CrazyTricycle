# CPU 内层折外关联实验

本轮完成了 6 个预先声明的配置，**没有采用新的关联分类器**。原 dictionary+nearest 的开发总分为 0.639727，最优 crossfit 配置为 crossfit_w0.5_t0.3，总分 0.639798；只有 2 折改善，关联 Macro F1 下降，未通过预设门槛。

原始与重新拟合的 CPU 外折预测完全一致；内层候选已逐文献检查，禁止自身、外折验证文献和 B 集提供上游标签。训练候选、完整来源声明、6 个配置的逐折结果及置信度均已保存。最佳开发 OOF 文件通过服务器及本机校验；没有创建该路线的 B 提交。

总分配对 bootstrap 描述性 95% 区间为 [-0.010926, 0.011424]，跨过零。这个结果不能证明改进有效；也不能证明内层候选生成本身无用，因为本实验同时使用患者平衡权重，且外折已用于多轮开发。
