# BIO 补充证据：两折试验与三折确认

结论：未晋级，不启动全量 BIO 拟合，不生成新的 B 文件。当前推荐文件仍为 `submissions/patientphex_b_context.jsonl`。两折试验中的收益在剩余三折明显缩小，不能据此前两折结果宣称稳定提升。

本次检验一个与先前 BIO 替换试验不同的问题：保留现有语义实体，只剔除未获得 BIO 跨度支持的短缩写，或增加互补的高置信度 BIO 实体。规则仅识别 2–8 字符的全大写/数字缩写，保留 NO 实体；BIO 支持须达到 0.5 置信度且重叠至少覆盖较短跨度的一半。候选补齐阈值固定为 0.8，语义相似度 0.9、间隔 0.02。

| 两折试验 | 平均总分增益 |
| --- | ---: |
| 仅剔除缺少 BIO 支持的缩写 | +0.009287 |
| 剔除并补齐 | +0.008594 |
| 仅补齐 | −0.000673 |

两折选定“仅剔除”，达到事先设定的平均增益 0.008 门槛。随后冻结该策略，在其余第 2、3、4 折训练相同配置的 BIO 模型，固定 5 个 epoch，不更改损失、学习率、随机种子或推理阈值。

后三折平均增益只有 0.000710，未达到冻结的 0.005 确认门槛。完整五折总分为 0.686504，较 0.681916 增加 0.004589，也未达到本次预设的 0.005 总分增益。四项 F1 为 0.719837、0.777697、0.659325、0.589160，均较基线提高，但收益不够稳定。

完整开发集实体 TP 从 4114 降至 4057，FP 从 1541 降至 1281；减少 260 个实体假阳性，同时多漏 57 个真阳性。关联 TP 从 1346 增至 1347，FP 从 581 降至 568。配对文档 bootstrap 的描述性 95% 增益区间为 [−0.000704, 0.009664]，跨过零。

新增三折训练分别耗时 135.70、154.60、129.44 秒，全部完成 5 个 epoch，零 AMP 溢出跳步。五折完整任务确认耗时 17.81 秒。GPU 0/2 上的训练已结束；第 3 块设备及其他用户作业未改动。服务器 120 项测试全部通过，本机独立复现五折分数并通过严格验证。

原上下文关联模型每折逐条复现后才进行修订；前两折的修订结果也与原试验逐条一致。所有保留实体仍是原实体对象，偏移、文本和 NO 标记没有重写。BIO 和关联模型的训练来源均按外折隔离，原始数据保持不变。
