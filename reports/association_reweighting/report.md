# 患者关联负例降权实验

本轮完成了一个预先声明的单变量实验：保持实体候选、五折划分、关联特征、患者均衡方式、C=0.5 和关联阈值 0.3 不变，只把未列入关联标注的候选关系的负例权重从 1.0 调为 0.5。

五折开发近似总分从 **0.601418 提高到 0.607801**，提升 **0.006383**，4 折改善、1 折下降，通过运行前写入的采用门槛。**仍低于冻结 CPU 对照的 0.639727**。所有分数均来自反复使用的 80 篇开发文献，不是独立测试分数，也不是 B 榜成绩。

随后按用户要求重新运行了面向 B 集的完整 CPU 对照，其新计算的开发分数仍为 0.639727，并生成了同一 B 集的 CPU 预测。该分数不是 A 榜官方成绩，也不能充当 B 榜成绩；详见 `reports/b_method_comparison/report.md`。截至本轮结束，用户尚无 B 榜官方反馈。
