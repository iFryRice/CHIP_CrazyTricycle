# BIO 边界模型两折试验

结论：未通过预先设定的扩展门槛，停止扩展其余三折，不生成 BIO 的 B 榜文件。现有语义映射候选保持不变。

使用相同的文档级五折分割，先在第 0、1 折分别训练 64 篇、验证 16 篇。两折均固定训练 5 个 epoch，不按验证成绩选择 checkpoint。基础模型为已固定版本的 BiomedBERT，损失为 O/B/I token 交叉熵。重叠金标准只在 BIO 训练投影时取最长非重叠跨度；评估保留全部原始金标准。

| 两折方案 | 平均完整任务分 | 相对同折语义基线 |
| --- | ---: | ---: |
| 当前语义映射基线 | 0.664797 | — |
| BIO + CPU/UMLS，阈值 0.5 | 0.662236 | −0.002562 |
| BIO + CPU/UMLS，阈值 0.8 | 0.661198 | −0.003599 |
| 仅 BIO，阈值 0.5 | 0.643753 | −0.021044 |
| 仅 BIO，阈值 0.8 | 0.627277 | −0.037521 |

训练前规定的扩展条件为平均完整任务分至少增加 0.008，且任一折下降不超过 0.005。四个预声明方案均未达到条件。最佳 BIO 方案两折分别变化 −0.005266、+0.000143。

两折精确跨度 F1 分别为 0.695449、0.669608；这不是比赛完整任务分。单独 BIO 方案的实体精度较高，但召回不足，完整任务分下降。当前证据不支持继续耗用 GPU 扩展该配置。

数值预检最初因 FP16 初始 GradScaler 过大出现梯度溢出。保留失败记录和代码修复差异后，将初始缩放设为 1024，重新冻结计划并通过 20 步烟雾测试。两折正式训练分别用时 132.56、154.56 秒，均完成全部更新、零 AMP 跳步，峰值显存约 6.03 GiB。

证据：`plan.json` 位于 `experiments/bio_ner/`；完整评分在 `pilot/summary.json`；训练完成记录在 `training-fold0/` 和 `training-fold1/`；数值失败记录为 `smoke_failure.json`、`smoke_failure.log`、`numerical_fix.patch`。服务器完整 checkpoint 保存在 `/home/dcf/chip2026/work/span_ner/bio-pilot-fold{0,1}/last.pt`。

服务器回归验证：108 项测试全部通过。本机同批测试运行 108 项，通过 97 项，11 项因未安装可选 PyTorch 而跳过。原始 A/B 输入及现有提交文件未改写。

这些结果来自反复用于开发的 32 篇文献，既不是独立测试结果，也不是五折或官方 B 榜分数。
