# 冻结实体预测的剩余误差

当前上下文模型的实体输出与上一版语义映射相同。对全部 80 篇开发文献按现有评分器逐项归因，实体 TP 4114、FP 1541、FN 1820。

| 金标准实体未匹配的原因 | 数量 |
| --- | ---: |
| 没有任何预测跨度重叠 | 941 |
| 重叠跨度、概念不同 | 439 |
| 重叠跨度、概念相同但边界不同 | 249 |
| 精确跨度被预测为 NO，金标准作为正例计分 | 97 |
| 精确跨度、概念不同 | 94 |

分类是按评分器与当前标注的差异计算，不代表每处原文的医学事实均已人工核定。例如 97 处 NO 差异中既有明确否定原文，也有“没有有效治疗”等并未否定表型本身的表达，不能统一改成正例以追逐标注。

缩写错误中可见文档内多义冲突，例如 NS、CNS 和 HE。文档定义试验已执行，结果见 `reports/document_abbreviations/report.md`；小幅正收益尚未达到晋级门槛。

下一优先级为利用已有 BIO 模型的补充证据：检验短缩写能否得到另一种边界模型支持，以及高置信度 BIO 实体是否补足原模型未重叠覆盖的内容。对应计划位于 `experiments/bio_corroboration/plan.json`，先做两折试验，避免直接投入完整重训。

完整计数、原文样例、频次和输入指纹见 `audit.json`，复现脚本为 `scripts/audit_entity_residuals.py`。原始数据和金标准均未修改。
