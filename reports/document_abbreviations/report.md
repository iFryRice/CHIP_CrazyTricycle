# 文档内缩写消歧试验

结论：最佳五折开发分从 0.681916 提高到 0.683887，增加 0.001971；五折均改善，但未达到训练前设定的 0.003 晋级门槛。因此不生成新 B 文件，当前推荐文件仍为 `submissions/patientphex_b_context.jsonl`。没有修改门槛或将微小增益重新包装成已晋级结果。

方法：从同一篇文献原文中的括号定义提取缩写及展开形式，再用仅在外折训练文献拟合的 HPO/UMLS 链接器解析展开形式。字符反向对齐思路参考 [Schwartz–Hearst (2003)](https://psb.stanford.edu/psb-online/proceedings/psb03/schwartz.pdf)，实现使用更严格的短形式过滤。发生冲突时保留原结果；新别名不传播到其他文献。关联模型、内层 CPU 训练候选、分割、阈值全部固定，并在每折先逐条复现原始上下文模型预测。

| 方案 | 五折开发总分 | 相对基线 |
| --- | ---: | ---: |
| 仅纠正 | 0.682055 | +0.000139 |
| 纠正并补齐 | 0.682410 | +0.000495 |
| 纠正并抑制无法映射的定义 | 0.683532 | +0.001617 |
| 纠正、补齐、抑制 | 0.683887 | +0.001971 |

最佳方案在开发集纠正 10 处、补齐 21 处、删除 64 处。实体 TP 增加 18、FP 减少 54；关联 TP 不变、FP 减少 4。四项 F1 依次为 0.715312、0.775793、0.657548、0.586893。逐折增益为 0.004880、0.000834、0.000779、0.001233、0.002161。

注意：展开形式无法被词库解析，不等于证明它不是表型。删除此类缩写是明确记录的试验开关，并非医学事实判定。最佳配置的描述性文档 bootstrap 增益区间为 [0.000543, 0.003835]，不能替代独立测试或官方成绩。
